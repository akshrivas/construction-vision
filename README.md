# Construction Vision — Web MVP

Simple **JavaScript** web app. Easy to run. Easy to test.

No AI. No native app yet. No Unity yet.

## Flow

Landing → Basic Requirements Form → Review House Spec → Enter Home (placeholder)

## Run

```bash
cd web
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Why JS first

- Fast feedback in the browser
- No Xcode / Unity setup to validate onboarding
- Same House Spec JSON can later feed a 3D walkthrough or native app

## Default form

- Plot: 30 × 50
- Floors: 2
- Bedrooms: 3
- Parking: 1

## Out of scope for now

- AI
- Auth / backend
- Native iOS/Android app
- 3D engine
- Marketplace / BOQ / vendors
